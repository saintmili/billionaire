# Milestone implementation checklist

This is a sequencing checklist derived from [the roadmap](roadmap.md), not a substitute for GitHub ticket status. Prepare individual issues with dependency links through the repository's ticket workflow when requested. Stop at each milestone acceptance gate.

- [x] **M0:** inspect the existing repo and pinned StopLore source; map public API, storage, license and gaps; verify Bybit contracts/connectivity; bootstrap Go and offline candle spike; record three ADRs and findings. Evidence: [M0 report](m0-report.md).
- [x] **M1** (after M0): pin used dependencies; add CLI/config/logging/shutdown/domain decimals; PostgreSQL Compose and versioned up/down migrations; init/config/status and CI. Gate passed: clean database round trip, invalid config rejection, documented install. Evidence: [M1 report](m1-report.md).
- [ ] **M2** (after M1; implementation complete, live-host gate pending): public spot/USDT-perpetual metadata, REST pagination, streaming and reconnect/backfill, persistent candles/aggregation, deterministic fixture feed. Gate: actual-host connectivity plus offline two-symbol/two-timeframe ingestion, gaps/staleness and duplicate tests. Offline checks passed; actual-host live connectivity remains unverified due geographic HTTP 403. Evidence: [M2 report](m2-report.md).
- [x] **M3** (offline acceptance passed under the roadmap sequencing exception): immutable strategy versions/instances, YAML/registry, as-of snapshots, emission/dedup policies and three reference strategies. Gate: preceding-20-candle breakout and future-data traps passed. Evidence: [M3 report](m3-report.md).
- [ ] **M4** (offline sequencing exception; [accounts #1](m4-accounts-report.md) [manual spot #2](m4-spot-report.md), [risk #3](m4-risk-report.md), [linear #4](m4-linear-report.md) and [protection #6](m4-protection-report.md) implemented, remaining acceptance pending): paper ledger/accounts, risk and manual/auto intents, simulated fills, isolated margin/funding/liquidation, stop/target/trailing/partial exits and kill switch. Gate: transactional/idempotent balances, precision and rejection invariants.
- [ ] **M5** (after M4): deterministic isolated replay, manifests/data hashes, metrics, reports/compare/exports. Gate: reproducible fixture runs, no look-ahead or mutation of forward paper accounts.
- [ ] **M6** (after M5): notification outbox/channels, foreground daemon, single-owner private socket, restart recovery, systemd/VPS runbook. Gate: outage/restart and headless behavior.
- [ ] **M6W** (after M6): private single-user operational web app over shared engine/risk services; signal approval/manual entry, positions/exits/adjustments, pause/resume, duplicate/lost-response handling, connection/freshness visibility, responsive desktop/mobile, system light/dark with remembered override, English text prepared for later translation. Gate: fixture-backed browser workflows and failure cases, private-access protections and runbook, theme/mobile checks. Charts, strategy editing, backtest configuration and multiple languages/RTL are deferred from the web scope.
- [ ] **M7** (after M6W; license resolved before dependency installation): pin/reinspect StopLore, implement modern decimal adapter, correlation/outbox, capability checks and reconciliation. Gate: real-library/PostgreSQL tests including partial exits and uncertain commit recovery; never duplicate a journal item through blind retry.
- [ ] **M8** (after M7): end-to-end fixture scenario including accepted M6W web workflows/themes/mobile behavior, race/failure/financial invariants, backup/restore, performance and operational evidence, release artifacts/docs. Gate: web acceptance passed, no blocking defects; obtain a current supported Go patch before release.
